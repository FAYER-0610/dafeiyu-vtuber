# 大肥鱼 · AI 尖塔直播主持

一个本机常驻的中文 AI 主播：**B站只收弹幕 + 只读 STS2-Agent → DeepSeek Key B → ElevenLabs → OBS 浏览器源**。游戏 Mod 继续用自己的 Key A 打牌；本程序不能直接操作游戏，也不发 B站弹幕，只能让 Mod 出手前等她说完一句（先说后打），以及把观众的打法建议摆给打牌的 AI 参考。

正式虚拟形象由独立页面实现，后端只负责协议、音频和静态服务。协议见 [docs/websocket.md](websocket.md)。当前正式形象目录是 `overlay/avatar/`，可独立替换，不要修改后端来切形象。

形象页支持 `video`、`layers` 和自研 WebGL 网格 `rig`，默认仍为 video。Rig 的切图/差分/物理与行为配置见 [docs/avatar-rig.md](avatar-rig.md)；零费用几何测试包可在 `/overlay/avatar/?renderer=rig&pack=packs/rig-test/rig.json&offline&debug` 预览，`rigdebug` 加网格与枢轴，1–6/Space/B/L/T/G/H 测试表情、嘴型与直播反应，V 切换模拟 viseme/音量口型。测试角色不是正式美术；嘴型优先跟随语音时间戳，缺失时回退音量三档。渲染故障会显示错误，不阻断音频和播放确认。

## 1. Windows 快速开始

工作目录就是本仓库根目录。现有 `.env` 请保留，**不要拿 `.env.example` 覆盖已有密钥**。

1. 双击 `login_bilibili.bat`，用**直播账号本身**（大肥鱼自己的号）的 B站 App 扫码并确认。二维码会同时打印在终端并保存为 `runtime\bilibili-login.png`。成功后脚本只更新 `.env` 的 `BILI_SESSDATA / BILI_JCT / BILI_BUVID3`，其他变量原样保留，并删除二维码。
2. 打开 `.env`，填写目标直播间的 `BILI_ROOM_ID`（房间号，不是 UID）；弹幕接收和下播动态都用这个房间和刚扫码的 Cookie。不要把 Cookie 发到聊天里。
3. 启动游戏，确保 Mod API 正常。游戏没开也可先启动主持程序，它会自动重连。
4. 双击 `start.bat`，创建/复用 Windows `.venv` 并安装依赖，然后启动 HTTP/WS 服务。默认 `http://127.0.0.1:8765`。
5. 按下面说明添加 OBS 浏览器源。**只有至少一个音频播放器就绪时才会调用收费模型/TTS**。
6. 开播/下播会从 B 站自动感知，也可以在控制页 `http://127.0.0.1:8765/overlay/control/` 手动按。下播后她会道别、整理记忆、写日记、发动态（见第 3 节“记忆与人味”）。
7. 停止用终端 `Ctrl+C`。这个项目不会自动推流，也不会改变游戏自动游玩开关。

命令行示例（CMD，进入工作目录后）：

```bat
start.bat --install-only
start.bat
start.bat --dry-run --max-speeches 1
start.bat --offline
start.bat --dry-run --live-game
login_bilibili.bat --generate-only
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe scripts\smoke_test.py
.venv\Scripts\python.exe scripts\probe_game.py
```

- `--dry-run`：**真实收费** DeepSeek + ElevenLabs，但用假弹幕/假游戏，不连接 B站；适合试声音。
- `--max-speeches 1`：最多完成一次播报后保持网页服务运行，不继续调用收费服务。
- `--offline`：隐含 dry-run，固定测试台词 + 1 秒轻提示音，**不是合成语音**，不调用收费服务。
- `--dry-run --live-game`：假弹幕 + 真实游戏只读观察；默认 dry-run 不碰游戏 API。
- `--port 8877`、`--config other.yaml` 可覆盖端口或配置；修改配置后重启。
- `scripts/smoke_test.py` 会在 8766 临时启动一个进程，用 Python WS 客户端模拟 avatar 播放/ACK，验证所有页面路由和音频，然后关闭测试进程；默认约 **1 次 LLM + 1 次 TTS**。加 `--offline` 可零费用跑。
- `scripts/probe_game.py` 仅 GET health/state 和订阅 18 秒 SSE，结果保存到 `runtime/game-probe.json`，不会人为启动战斗。

## 2. OBS 浏览器源

**省事做法**：关掉 OBS，运行 `python scripts/make_obs.py`，它会生成配置文件和场景集合 `DaFeiYu`（1920×1080 60 帧，下表的来源全部摆好），再写一个 `obs.bat`；以后双击 `obs.bat` 开 OBS。现在声音和画面靠 Mod 的“先说后打”对齐（见第 3 节），`overlay.game_delay_seconds` 是 0，游戏采集直接放进画框。如果改成几秒的延迟再跑脚本，它会换成延迟做法：「游戏原画」场景只放游戏采集，虚拟摄像机输出这个场景，正式场景「大肥鱼直播」把虚拟摄像机接回来挂「视频延迟（异步）」滤镜，游戏声音设同样的同步偏移；这时**虚拟摄像机没开，游戏区域就是黑的**（`obs.bat` 会自动开）。改了延迟或 `overlay.game` 就关掉 OBS 重新跑一次脚本。原有的配置文件和场景集合不会被改动。

手动搭的话照下表：

全部设 **1920×1080**、透明背景、位置 0,0，同一台机器使用本机地址。画面布局：左栏状态卡 + 弹幕，右侧带边框的游戏画面，游戏下方字幕条，右下角形象。**OBS 来源列表从下到上**：

| 顺序（下→上） | 来源 | 地址 / 设置 | 说明 |
|---|---|---|---|
| 1 | 游戏采集 | 游戏窗口采集，变换到 **x=456 y=24 宽1440 高810** | 被舞台背景的透明洞框住 |
| 2 | 舞台背景 | `http://127.0.0.1:8765/overlay/stage` | 深海背景 + 游戏画框，游戏区域是透明的 |
| 3 | 状态卡 | `http://127.0.0.1:8765/overlay/status` | 左上：标题、直播状态、游戏/出牌/弹幕/语音、角色/层数/画面/HP |
| 4 | 弹幕 | `http://127.0.0.1:8765/overlay/danmaku` | 左栏：普通弹幕气泡、礼物、醒目留言、上舰、进场 |
| 5 | 字幕 | `http://127.0.0.1:8765/overlay/subtitle` | 游戏下方：说话时按语音时长逐字出现，空闲时空着（断线时显示“重连中”） |
| 6 | 正式形象 | `http://127.0.0.1:8765/overlay/avatar` | 唯一音频播放器；右下位置由 avatar.json 控制 |
| — | 测试播放器 | `http://127.0.0.1:8765/overlay/avatar-placeholder` | 仅供调试，不是正式形象 |

整体效果可在普通浏览器打开 `http://127.0.0.1:8765/overlay/preview/` 预览（加 `?avatar` 会叠上形象页并占用语音播放端，直播时别开着）。

- **声音只来自形象浏览器源**。在 OBS 对该源勾选“通过 OBS 控制音频”，再在高级音频属性里选择适合的监听/输出方式。不要同时用桌面音频重复采集同一段声音。
- 正式直播时移除/关闭占位播放器，以及其他标签页里的正式形象；多开时只有第一个就绪的 avatar 获得播放权，其他待机。
- 普通浏览器若禁止自动播放，点击“启用声音”。OBS 通常允许自动播放。
- 建议不勾选“不可见时关闭源”；否则切场景会断线，当前语音需等超时兜底。不想在隐藏时继续说话可主动关闭形象源。
- 页面断线立即停止音频；当前语音不重播。后端等时长+12秒再结束本句，避免重叠。连续 ACK 超时 1/2 次后冷却 30/60 秒；第3次需点击人工恢复。
- 同源 `.webm` 支持 URL 编码中文路径、`video/webm`、Range/206。第三方动画包的授权和 OBS 端 VP9 透明解码兼容性由形象页面单独核验。
- 弹幕/状态/字幕 URL 加 `?preview` 可在普通浏览器显示深蓝预览背景；OBS 不加这个参数。

## 3. 配置与费用

`config.yaml` 可配置：

- `server.port / banner`：监听端口、顶部文案。只允许 loopback 监听，不提供公网部署模式。
- `overlay.game` / `overlay.danmaku`（left / top / width / height）：1920×1080 内游戏画面区域和弹幕栏位置，由 status 消息下发；状态卡和字幕条自动对齐。改了 `overlay.game` 要同步改 OBS 里游戏采集的位置。
- **先说后打**：打过补丁的 STS2-Agent Mod 在执行每一步之前，会把动作和思路 POST 到 `http://127.0.0.1:8765/api/narrate`（地址写在 `%APPDATA%\STS2AIAgent\narrator.txt`，删掉这个文件就关掉）。值得说的一步会排到最前面，她说完 Mod 才出手；不值得说的立刻放行。战斗里：游戏 AI 每回合先想好整套出法（第一步的思路就是整回合的打算，后面几步不再问 DeepSeek，中途抽到新牌、弹出选择、目标死了就作废重想），她在第一张牌前说一句这回合的打算（不预言下回合、不断言敌人死不了），保命这类关键操作再说一句，其余出牌不说，两句至少隔 `game.combat_gap_seconds`（20 秒）；斩杀（思路里明确写着 lethal / kills it / 斩杀，“打不死”这类否定不算）不受这个间隔限制，一定说一句收掉它。局面卡上残血（≤10 点或 ≤10%）的敌人标“快死了”。战斗外的选路、选卡、买东西、选事件按 `game.decision_cooldown_seconds`（60 秒）冷却。先说后打在工作时，战斗里不再补“每分钟至少几句”的保底台词。5 秒内轮不到她（前一句还没念完、限额满了）就不说这步；整步最多让游戏等 10 秒，Mod 那边上限 20 秒。主播程序没开或形象页没开时立刻放行，不会卡住游戏。这个接口只收本机程序发来的 JSON，浏览器跨站请求一律 403；主播程序依然不能操作游戏，只能让它晚一点出手。
- `overlay.game_delay_seconds`：OBS 里给游戏画面加了延迟（让画面和她的语音对上）就填同样的秒数，状态卡的角色/层数/画面/血量会一起晚显示；默认 0。OBS 自带“渲染延迟”滤镜单个最多 0.5 秒，`scripts/make_obs.py` 用虚拟摄像机绕一圈实现更长的延迟（见第 2 节）。
- `persona`：名字和角色卡路径。性格、说话方式都在 `memory/角色卡.md`（傲娇嘴硬、正事靠谱的大肥鱼），随时打开改，保存后下一句就生效。
- `brain.requests_per_minute: 6`、`requests_per_hour: 300`：**所有 LLM 尝试**的滚动限额，包括失败；不是仅成功回复计数。
- `brain.game_text_chars: 20`：牌局台词（含先说后打）只说一句、最多 20 字，约 2~3 秒；回弹幕仍按 `max_text_chars`。牌局台词绑定产生时的画面，想台词期间画面变了（比如仗打完了）就丢掉，不念也不花 TTS。
- `brain.game_lines_per_minute: 4` / `game_lines_min_per_minute: 1`：牌局解说每分钟最多/至少几句。在一局里一阵子没说牌局时，她会自己挑个角度（手牌、敌人意图、路线、卡组…）聊一句；回弹幕不占名额。
- `chat_replies_per_minute: 2`：弹幕回答额外限额。游戏大事件不能突破总体费用上限。
- `min_gap_seconds: 10`：两次 LLM 请求最小间隔；单一 worker 等待播放 ACK，正常不会语音重叠。
- `max_tokens: 180`、`max_text_chars: 110`：每次回答上限；输出仅一到两句。
- `idle_seconds: 100`：队列空且长时间安静后才闲聊。
- `chat_reply_all: true` / `chat_user_replies_per_minute: 3`：人少的时候每条弹幕都回，但同一个观众一分钟最多回 3 条。回弹幕时她会在话里叫出对方昵称（开头、中间、结尾都行；粉丝牌括号、表情符号会去掉）。模型漏了的话，程序在句首补上“昵称，”。不安全的昵称、匿名“观众”不叫。牌局台词不叫人。
- **观众引导打法**（`guidance_*`）：她回弹幕时顺便判断这条是不是打法主意（出哪张、先打谁、走哪条路、拿什么卡…），是就简化成一句挂到“观众建议板”上（`GET /api/guidance`，只读、仅本机）。全场 20 秒收一条、同一人 60 秒一条，每条挂 90 秒，最多 3 条。打补丁的 Mod 像 Codex 的“引导”那样用它：每次决策开始时摆在 DeepSeek 面前；整回合计划执行中来了新建议，就把没出完的计划连同建议交回去让它改；它查资料的两轮思考之间来了新建议，就接在同一段对话后面。建议只是参考，不合理、送死、捣乱的它不听，非法操作照样做不了；它在思路里点了谁的名，她出手前会说一句听没听。正在生成的那段思考改不了，建议落在最近的衔接点。
- `chat_batch_seconds: 8`：合并类似弹幕，挑问题/支持消息，最多取3项构成一次主题，不承诺每条都回。
- `topic_ttl_seconds: 50`、有界队列与去重：过时话题丢弃，不追着十分钟前的弹幕读。
- `audio`：默认30分钟保留、最多160文件/100MB；每分钟清理，保护正在播放的音频。可随时在停机后删 `runtime/audio/`。
- `safety.extra_blocked_words`：本地追加屏蔽词。不要放入密钥。

`.env` 仅存凭据和服务标识，按**文件读取**，不从进程环境默默覆盖：

| 变量 | 用途 |
|---|---|
| `DEEPSEEK_HOST_API_KEY` | 主播专用 Key B，不读取 Mod Key A |
| `DEEPSEEK_BASE_URL` | 官方 `https://api.deepseek.com`（或其 `/v1` 路径）；拒绝非官方主机避免密钥误发 |
| `DEEPSEEK_HOST_MODEL` | 只允许 `deepseek-chat`，非思考模式 |
| `ELEVENLABS_API_KEY / ELEVENLABS_VOICE_ID` | TTS 凭据、用户自己的 voice id |
| `ELEVENLABS_MODEL` | 默认 `eleven_v4_turbo`（音质接近 v4、点数和 Flash 一样、合成约 2.6 秒），中文 `language_code=zh`，`mp3_44100_128`；`eleven_flash_v2_5` 更快更省但表情少，`eleven_v4` 表情最好但点数翻倍、合成约 5 秒 |
| `STS2_AGENT_URL` | 默认 `http://127.0.0.1:8080`，只允许本机 HTTP |
| `BILI_ROOM_ID / BILI_SESSDATA / BILI_JCT / BILI_BUVID3` | 房间与直播账号扫码凭据（读弹幕、下播发动态共用） |

不要把 `.env`、二维码、Cookie 或整个浏览器测试 profile 上传仓库。`.gitignore` 已排除 `.env` 和 `runtime/`。API 日志不会打印请求头、上游响应体、提示词或密钥；默认也不记录弹幕全文。

### 记忆与人味

大肥鱼的性格和记忆都在 `memory\` 里，全是 Markdown，用记事本打开就能看、能改，保存后下一句话就生效：

| 文件 | 内容 | 谁写 |
|---|---|---|
| `角色卡.md` | 她是谁、怎么说话（傲娇嘴硬、正事靠谱、对直播上心） | 只有你；程序永远不写 |
| `关于我.md` | “数据”（场次、时长、最远层数、通关次数）和“我记得的事” | 下播后程序更新，你随便改 |
| `熟人.md` | 说过话的观众：昵称、uid、外号、来过几场、她的印象 | 下播后程序更新；你起的外号和自己加的行不会被覆盖；删掉一节就是忘了这个人 |
| `梗.md` | 直播间自然出现的梗 | 下播后程序追加 |
| `日记\` | 每场一篇，末尾“## 动态”是发到 B 站的那段话和发布结果 | 下播后程序写 |
| `备份\` | 程序每次改文件前的旧版本，`修改记录.md` 记了改了什么 | 程序；想回滚就把备份复制回去 |

下播整理时别开着这些文件编辑，免得编辑器把新内容盖掉。

直播中她会这样：
- **挑着回**：被点名、提问、第一次开口的人、熟人优先，而且排在日常牌局话题前面；普通闲聊看直播间气氛随机接（冷清时全接，平常约四分之三），不逐条回。
- **打牌不耽误聊天**：卡牌游戏没有出牌时限，打 Boss、残血时照样正常回弹幕；牌局只是聊天素材。
- **打牌时话少**：战斗中只讲斩杀、保命这类关键操作（至少隔 1 分钟）；选卡、买东西、选事件这类决定照常聊。牌局解说每分钟最多 2 句，排队 15 秒没轮到、或者想好时已经过去 25 秒就不说了，免得语音落后画面。残血、精英/Boss 开打、通关或倒下不受限。
- **看得到局面**：每句话都附一张实时局面卡（血量、能量、手牌、敌人意图、遗物、药水、卡组），被问到牌局能说到具体牌名和数字。
- **有心情**：输了会不甘心一阵，通关会得意一阵，心情会慢慢淡掉。
- **认得人**：熟人进场偶尔打招呼，可以叫外号；限频，同一个人一场只招呼一次。
- **冷场找话**：轮流从牌局盘算、记得的事、在场熟人、时间、直播小目标、梗里找话题。
- **开播和下播**：开播会提一句上次日记，下播先道别。

下播（B 站下播信号、控制页按钮，或程序被关掉后下次启动时发现已下播）后，用 key B 调一次 DeepSeek（约几千 token），写日记、补熟人印象、记新梗。发给模型的只有昵称、弹幕和印象，uid 只留在本地。生成内容逐条过本地安全过滤，不过关的直接丢弃。

`config.yaml` 的 `diary` 段：
- `dynamic: auto` 下播后自动发一条纯文字动态（唯一的 B 站写操作，一次、不重试）；`draft` 只存草稿；`off` 不写动态。离线和 dry-run 模式永远不发。
- `min_minutes: 10` 播不到 10 分钟只记数据，不写日记、不发动态。

动态没发出去时，草稿还在日记里。检查登录（只读）：`.venv\Scripts\python.exe tests\probe_dynamic.py`；确认后手动补发：加 `--post`。

### 14种表情情绪

主播大脑可输出 `neutral/happy/excited/surprised/sad/angry`，以及新增的 `shy` 害羞、`smug` 得意、`confused` 疑惑、`cry` 哭哭、`pout` 鼓脸、`starry` 星星眼、`dizzy` 晕乎乎、`playful` 吐舌眨眼。系统提示逐项说明场景：被夸/收礼可害羞，有依据的好操作可得意，奇怪事件/怪物可疑惑，明确大额受伤/失败可哭哭，一次挨很多伤害可晕乎，确认稀有卡/心仪遗物或精英胜利可星星眼，小失误可鼓脸，玩笑卖萌可吐舌眨眼；仍不辱骂、不责怪玩家、不引导消费。

合法值必须精确小写，缺失/未知/非字符串回落neutral；长度、输出安全、token/请求预算不变。情绪枚举和场景提示来自同一份后端定义，防止提示词与校验漂移。当前GameTopics没有事件→emotion硬映射，因此只做事实约束的模型提示，不新增或臆造游戏字段。当前低HP不等于刚挨大伤，combat_ended不等于精英获胜，奖励/卡名不等于稀有卡；证据不足选neutral/confused。完整场景见 `docs/websocket.md`，具体美术表情仍由独立形象页实现。

### 读音口型时间轴

ElevenLabs合成使用 `/v1/text-to-speech/{voice_id}/with-timestamps`，模型、中文参数和MP3格式不变，解码响应里的audio_base64。接口失败不会静默改走普通合成接口，也不自动重试。

`speech.visemes` 是可选的 `{t:秒, v:A/I/U/E/O/N}` 时间轴：**合法原文alignment含中日韩文字时优先原文**，否则优先同一响应的normalized_alignment，normalized无效再用原文。真实验证发现12字符中文原文会变成37字符normalized，不能把后者无条件当成更准确的中文读音；逐汉字映射可避免误把罗马化字母按英文处理。两者都空/无效时返回空数组，音频仍可播放，不伪造真实对齐。

时间保留3位小数，相邻同形合并，标点/空白/大于0.12秒停顿闭口N，结尾N，最多600项。短于60ms的非N段并入相邻开口；孤立在N之间的极短开口抑制，N停顿即使短于60ms也保留，避免嘴型抖动。每个中文字符按韵母选一个主口型、不拆复合韵母；原文数字按中文单个数字近似（2→E、8→A），不虚构“28”中间“十”的时间。英文仅简单近似，不提供日/韩读音识别；这不是声学音素级口型识别。完整映射和播放时钟规则见 `docs/websocket.md`。离线模式也有按文本均分的口型，仅为1秒测试音的视觉联调样本，不是真实读音。

新增本地依赖 **pypinyin==0.55.0（MIT）**，上游 https://github.com/mozillazg/python-pinyin ，许可证 https://github.com/mozillazg/python-pinyin/blob/master/LICENSE.txt 。安装包保留其许可证；重新分发包/源码时保留版权和MIT许可声明。Windows启动脚本本来就安装requirements，无须额外全局安装；WSL需同步更新独立venv。缺少中文映射依赖时在收费请求前报错。

## 5. 数据流与只读边界

```text
blivedm 回调 → 有界 ingress → 本地安全过滤 → 安全弹幕列表 / 8秒合并
STS2 SSE + 8秒状态快照 + 20秒决策补查 → 话题提炼
                         ↓
优先级队列（死亡/通关、残血、Boss/精英 > 一般战斗/选卡 > 弹幕 > 冷场）
                         ↓
滚动限额 → DeepSeek JSON台词/情绪 → 输出安全检查 → ElevenLabs
                         ↓
本地音频文件 → WS speech → 唯一 avatar Audio/WebAudio → speech_done
```

- SSE 支持多行 `data:`、心跳注释、断线重连。服务端没有事件历史重放，重连后读新快照补齐当前状态，不幻想补回断线期间所有事件。
- 允许访问的游戏路径只有 `GET /health /state /decisions /events/stream /data/monsters`。`/data/monsters` 每个游戏进程仅缓存读取一次，用于精英/Boss级敌人识别；**没有 POST/action/session/control**。反方向只有一条：打过补丁的 Mod 出手前会主动来问 `POST /api/narrate`，主播程序最多让它晚一点出手，不能改动作、不能拦截（见第 3 节“先说后打”）。
- 状态字段按实际 snake_case（兼容 PascalCase）处理。本局编号是 API 的 run_id 种子，不是自行计数。
- 开战、低血量跨阈值、结束、GAME_OVER胜负、奖励、商店、事件、每层推进均有话题。已接受决策的公开 reason 限流转述；API没给具体卡名时不编造卡名或隐藏思维。
- Boss/Elite 优先使用直接类型/当前地图节点；缺失时参考怪物元数据，并明确是敌人等级，不武断把事件召唤怪说成Boss房。
- `combat_ended` 本身不证明胜利：只描述战斗结束；`game_over.is_victory` 才决定通关/失败。
- 部分实战画面/卡牌选择形式仍需用户实机观察；不保证能对每张牌逐张解说。

## 7. 内容安全与限制

不安全弹幕在进模型和进网页之前本地丢弃：政治、色情、辱骂、引战、广告引流等；做 Unicode 规范化、URL/联系方式、词表检查。套话/越狱内容不显示、不传原文，只进入一个低频的固定礼貌带过话题。昵称/粉丝牌同样检查；头像限定 HTTPS B站CDN；网页文本使用 textContent。

DeepSeek 没有任何工具、文件访问或密钥上下文，系统角色明确外部内容不可信，输出再检查、限制情绪枚举/长度/句数。没有播放器时不生成台词；输入再多也受队列、时效和分钟/小时预算约束。

**这不是“绝对合规”认证。** 词表/提示不能覆盖所有谐音、时事暗语和新型提示注入；模型可能判断错误或幻觉。上线需人工值守、按平台最新规则补充屏蔽词、配置适度额度，发现异常立刻关闭形象源或停止进程。第三方TTS声音与动画包要确认直播/商业使用授权。程序用的是直播账号本身的 Cookie，所以写操作压到最少：不发弹幕，每场最多发一条下播动态，失败不重试。Cookie 过期就重新扫码。

服务无公网认证机制，只接受本机 Host 和同源浏览器 Origin，不开放 CORS。不要映射/代理端口到公网。原生本地WS客户端属于本机信任边界，可注册播放器；它不是为多租户设计的。
